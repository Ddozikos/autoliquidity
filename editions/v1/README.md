# Редакция 1 — функциональный MVP

Назначение: разработка и проверка сценария на тестовых данных. Здесь включаются реальные интеграции, если предоставлены разрешённые API-доступы. Не использовать для настоящих документов с персональными данными: вход сейчас демонстрационный, облачный GigaChat может получать текст документа.

Запуск и переменные окружения описаны в корневом [README](../../README.md). Редакция является текущим состоянием общей кодовой базы, а не отдельной сборкой.
